# 單字大冒險（english-word-quest）

小三英文家教用的單字練習 PWA。單檔 HTML，沿用 `chinese-word-quest`（生字大冒險）的遊戲外殼，
核心關卡整個換成英文、而且**全部自動判分**——因為目的是讓孩子自己在家練，不是老師在旁邊改。

## 為什麼是這三個關卡

對應讀書計劃的「聽 → 說 → 拆 → 寫」四步驟（見 `tutoring/小三英文規劃/`）：

| 畫面 | 練到什麼 | 對應步驟 |
|---|---|---|
| 📖 學新字 | 強制先聽 3 次才給看字 → 再看音塊拆解 | 聽 / 說 / 拆 |
| 🔊 聽音選字 | 音 → 形 | 聽 |
| 🔤 看字選意思 | 形 → 義 | — |
| 🧱 拼字磚 | 產出（點字母磚，不用鍵盤） | 寫 |
| 📝 今天要寫的 5 個字 | 抄進紙本練習本 | 寫 |

**為什麼拼字用字母磚不用打字**：八歲的孩子英打很慢，用鍵盤的話一題有一半時間在找按鍵，
練的會變成打字而不是拼字。Anki 的 `{{type:}}` 卡有同樣問題（見工具比較文件）。

## 練習本與 App 怎麼接起來

家長很重視「寫」，所以有紙本練習本；但純抄寫效果差，所以做成閉環：

1. 安親班回來 → **先玩 App 10 分鐘**（聽音選字／看字選意思／拼字磚）
2. 答錯的字自動進「**單字寶箱**」
3. 打開「**今天要寫的 5 個字**」→ 清單優先從單字寶箱撈，**照著抄進練習本 10 分鐘**
4. 隔天 App 再考那幾個字，答對三次才移出寶箱

**每個字寫 5 次，但 5 次動作不同**：前 2 次看著抄（同時唸出來），**後 3 次蓋起來寫**。
家長看到的還是「寫五次」，實質上後三次是提取練習——這是刻意設計，不是妥協。

清單**每天固定**（同一天重開 App 不會換一份新的字），存在 `store.write`。

## 單元 ＝ 日期

一個單元就是一天，固定 **5 個字**，全部都要寫（不是只挑錯的）。
首頁的「今天的功課」自動對應到今天日期的單元；今天沒有單元就跳到第一個還沒寫完的。

每個字有 `img` 欄位放一個 emoji 當圖卡——五步驟裡的第 3 步「看」就是看它。
沒有拼讀／詞彙的分別了，全部都是詞彙單元。

## 抄寫單：一口氣寫完 5 個字

「📝 要寫的 5 個字」是這個 App 的主畫面：一頁列出當天 5 個字，每個字有
**圖 ／ 英文 ／ 詞性 ／ 中文 ／ 音塊**，照著抄進紙本練習本，寫完按「寫好了」。
頂端固定顯示五次的規則（前 2 次看著抄、後 3 次蓋起來寫）。

## 音塊怎麼拆（`chunks` 欄位的規則）

兩層，不要混用：

1. **多音節字先切音節**（一個母音「音」＝一個音節）：`pen-cil`、`hap-py`、`o-pen`
2. **單音節字切「首音 ＋ 韻腳」**：`c-at`、`sh-op`、`st-op`
3. **不再往下切成單一字母**——`-at` 當一整塊記，字族類推才生效；切成 `a-t` 就失效了
4. **母音開頭的單音節字**切「母音組合 ＋ 尾音」：`ea-t`
5. **不規則字不切**，標 `sight:true`（write、friend）

> v3 之前的資料混用了三種切法（`b-oo-k` 逐字素、`c-at` 首音韻腳、`hap-py` 音節），已統一。
> `build_words.py` 的自動切字只處理單音節（onset-rime），多音節一律留空要人工填——寧可空著不要切錯。

## Leitner 三盒

- 答對 → 往上一盒（0→1→2→3），**答對三次才變 💎精通**
- 答錯 → 一律退回第 1 盒，並進「寶藏袋」
- 出題比例：第 1 盒每次都出、第 2 盒出一半、第 3 盒出四分之一

## 換成安親班的真實單字

```bash
python3 build_words.py 安親班單字表.tsv     # 覆寫 data/words.js
```

TSV 格式看 `build_words.py` 的說明。單音節字的音塊會自動切（cat→c-at），
多音節字會留空並提醒——**寧可空著，不要自動切錯教壞小孩**。

## 本機跑起來

```bash
python3 -m http.server 8123
open http://localhost:8123/
```

⚠️ **改完程式看不到變化**：Service Worker 是 cache-first，會一直餵舊版。
開發時先在 Console 跑：

```js
for (const r of await navigator.serviceWorker.getRegistrations()) await r.unregister();
for (const k of await caches.keys()) await caches.delete(k);
location.reload();
```

發版時 `APP_VER`（index.html）和 `CACHE`（sw.js）**兩個都要改**，使用者端才會自動更新。

## 已知限制

- **音塊發音是逼近值**。TTS 唸單獨的子音會唸字母名稱（c → "see"），程式補了一個 uh
  變成 "cuh" 才唸得出「音」。這只是權宜；正確的音還是要老師當面示範。
- 地面的動物是固定 5 隻。蛋、圖鑑、商店、合成台都還沒做（第二階段）。
- **CSS class 命名要避開既有的**：`.wstep.cover` 撞到抽考的 `.cover`（`position:absolute; inset:0`），
  整頁被撐滿。已改成 `.s-cov`。加新元件前先 grep 一次 class 名。
- 沒有雲端同步，進度存在該裝置的 localStorage。換裝置＝重來。

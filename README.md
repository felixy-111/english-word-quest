# 單字大冒險（english-word-quest）

小三英文家教用的單字練習 PWA。單檔 HTML，沿用 `chinese-word-quest`（生字大冒險）的遊戲外殼，
核心關卡整個換成英文，目的是讓孩子自己在家練，不是老師在旁邊改。

## 首頁＝家長提案的「每天 20 分鐘」

App 的主線**完全照著給家長的提案**（`tutoring/小三英文規劃/05_家長提案_新版.pdf`）走，
首頁就是那三段，不多不少：

| 首頁 | 內容 | 提案裡的時段 |
|---|---|---|
| ① 複習昨天的 5 個字 | 圖＋中文 → 自己想 → 翻答案 → 自評 | 0–3 分 |
| ② 今天的 5 個新字 | 聽 → 說 → 看 → 拆 → 寫（最後接抄寫單） | 3–18 分 |
| ③ 蓋起來默寫 | 圖＋中文 → 寫在練習本上 → 翻答案對一對 | 18–20 分 |

① 和 ③ 是同一支程式 `startRecall(uid, mode)`，差別只在拿哪個單元和文案（`RC` 常數）。
**兩段都是自評，不自動判分**——提案講的就是「寫在練習本上」，字在紙上，App 只負責出題、
翻答案、記下哪幾個字要明天先練。

`③ 蓋起來默寫` 的結算會列出寫錯的字並說「圈起來，明天先練」，
隔天這些字就在 ① 出現（它們同時進了單字寶箱）。

### 為什麼砍掉選擇題

原本有「🔊 聽音選字」「🔤 看字選意思」兩個四選一關卡，v6 拿掉了。
四選一是**認得出來**，提案整套要的是**想得出來**——給了四個選項就等於給了提示，
跟提取練習牴觸。只留「🧱 拼字磚」當加碼練習（在單元頁裡）。

**為什麼拼字用字母磚不用打字**：八歲的孩子英打很慢，用鍵盤的話一題有一半時間在找按鍵，
練的會變成打字而不是拼字。Anki 的 `{{type:}}` 卡有同樣問題（見工具比較文件）。

## 練習本與 App 怎麼接起來

家長很重視「寫」，所以有紙本練習本；但純抄寫效果差，所以做成閉環：
① 想不出來的字 → 進單字寶箱 → ② 今天照樣要寫 → ③ 默寫寫錯的 → 隔天 ① 先練到。
答對三次才移出寶箱。

**每個字寫 5 次，但 5 次動作不同**：前 2 次看著抄（同時唸出來），**後 3 次蓋起來寫**。
家長看到的還是「寫五次」，實質上後三次是提取練習——這是刻意設計，不是妥協。

清單**每天固定**（同一天重開 App 不會換一份新的字），存在 `store.write`。

## 單元 ＝ 日期

一個單元就是一天，固定 **5 個字**，全部都要寫（不是只挑錯的）。
首頁的「今天的功課」自動對應到今天日期的單元；今天沒有單元就跳到第一個還沒寫完的。

沒有拼讀／詞彙的分別了，全部都是詞彙單元。

## 圖片：ARASAAC，不是 Google

`img/<單字>.png`，由 `fetch_images.py` 從 **ARASAAC**（西班牙 Aragón 政府的溝通輔具圖庫）抓下來。

```bash
python3 fetch_images.py            # 只補還沒有的圖
python3 fetch_images.py --force    # 全部重抓
```

- **不能用 Google 圖片**：搜出來的圖絕大多數有版權，抓下來放進這個公開 repo 就是侵權。
- ARASAAC 授權 **CC BY-NC-SA**，非商業教學用途可用，出處標在 App 的「❓ 怎麼玩」頁面底部。
- 抓 `https://static.arasaac.org/pictograms/{id}/{id}_300.png`：彩色、300×300、約 8KB。
  ⚠️ 不要改用 API 的 `?resolution=500`（18–29KB），也不要拿 `sips` 縮圖（重新編碼後反而漲到 38KB）。
- `bestsearch` 的第一名有時語意對不上（fish 挑到「盤子裡的魚料理」、bag 挑到紙購物袋、
  rice 挑到稻穗），所以腳本裡有 `OVERRIDE` 表指定正確 id。**加新字後要逐張看過**。
- 抽象詞是最大風險。`big` ARASAAC 只有紅方框比大小或 XL 吊牌，小三看不懂，
  所以 `img/big.png` 是**手工合成的**（同一隻大象一大一小並排）。腳本會跳過已存在的檔，不會蓋掉。
- `words.js` 的 `emoji` 欄位是**退路**：圖檔 404 時 `onerror` 會換成 emoji，
  離線第一次開、或新字還沒抓圖，都不會開天窗。**不要拿掉這個欄位。**
- 動詞可以加 `anim` 欄位（`hop`／`shake`／`pulse`）做 CSS 微動效，
  只在「看」和翻答案時播，**抄寫單不播**（寫字時會分心）。沒有用 GIF。

## 抄寫單：一口氣寫完 5 個字

「📝 要寫的 5 個字」是這個 App 的主畫面：一頁列出當天 5 個字，每個字有
**圖 ／ 英文 ／ 詞性 ／ 中文 ／ 音塊**，照著抄進紙本練習本，寫完按「寫好了」。
頂端固定顯示五次的規則（前 2 次看著抄、後 3 次蓋起來寫）。

## 音塊怎麼拆（`chunks` 欄位的規則）

兩層，不要混用：

1. **多音節字先切音節**（一個母音「音」＝一個音節）：`pen-cil`、`hap-py`、`o-pen`
2. **單音節字切「首音 ＋ 韻腳」**：`c-at`、`sh-op`、`st-op`
3. **不再往下切成單一字母**——`-at` 當一整塊記，字族類推才生效；切成 `a-t` 就失效了
4. **母音開頭的單音節字**切「母音組合 ＋ 尾音」：`ea-t`
5. **不規則字不切**，標 `sight:true`（write、friend）

> v3 之前的資料混用了三種切法（`b-oo-k` 逐字素、`c-at` 首音韻腳、`hap-py` 音節），已統一。
> `build_words.py` 的自動切字只處理單音節（onset-rime），多音節一律留空要人工填——寧可空著不要切錯。

## Leitner 三盒

- 答對 → 往上一盒（0→1→2→3），**答對三次才變 💎精通**
- 答錯 → 一律退回第 1 盒，並進「寶藏袋」
- 出題比例：第 1 盒每次都出、第 2 盒出一半、第 3 盒出四分之一

## 換成安親班的真實單字

```bash
python3 build_words.py 安親班單字表.tsv     # 覆寫 data/words.js
```

TSV 格式看 `build_words.py` 的說明。單音節字的音塊會自動切（cat→c-at），
多音節字會留空並提醒——**寧可空著，不要自動切錯教壞小孩**。

## 本機跑起來

```bash
python3 -m http.server 8123
open http://localhost:8123/
```

⚠️ **改完程式看不到變化**：Service Worker 是 cache-first，會一直餵舊版。
開發時先在 Console 跑：

```js
for (const r of await navigator.serviceWorker.getRegistrations()) await r.unregister();
for (const k of await caches.keys()) await caches.delete(k);
location.reload();
```

發版時 `APP_VER`（index.html）和 `CACHE`（sw.js）**兩個都要改**，使用者端才會自動更新。

## 已知限制

- **音塊發音是逼近值**。TTS 唸單獨的子音會唸字母名稱（c → "see"），程式補了一個 uh
  變成 "cuh" 才唸得出「音」。這只是權宜；正確的音還是要老師當面示範。
- 地面的動物是固定 5 隻。蛋、圖鑑、商店、合成台都還沒做（第二階段）。
- **CSS class 命名要避開既有的**：`.wstep.cover` 撞到抽考的 `.cover`（`position:absolute; inset:0`），
  整頁被撐滿。已改成 `.s-cov`。加新元件前先 grep 一次 class 名。
- 沒有雲端同步，進度存在該裝置的 localStorage。換裝置＝重來。
- **單元 id 是日期字串**（`"2026-09-04"`），不是數字。`+c.dataset.uid` 會變成 `NaN`，
  整個「選一個單元」會死掉（v5 踩過這個雷）。碰到 uid 時不要轉型。
- 圖片**不能放進 sw.js 的 `ASSETS`**：`addAll` 只要有一張 404 就整包安裝失敗。
  改成 fetch handler 對 `/img/` 走 cache-first 再回填。
